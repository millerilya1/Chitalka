# Читалка

Android-приложение для чтения манги из своего файла `.chitalka`. Сервера нет: файлы собираются локально и передаются как угодно (в том числе через Telegram).

## Формат `.chitalka`

Это обычный ZIP (как CBZ), плюс манифест и обложка:

```
title.chitalka
├─ meta.json
├─ cover.jpg
└─ chapters/
    ├─ 001/001.jpg
    └─ 002/001.jpg
```

`meta.json` хранит название, автора, дату, список глав. Пример: `format/example-meta.json`.

Собрать файл на ПК: дважды щёлкните `tools/Собрать chitalka.bat` (нужен Python 3). Для превью обложки: `pip install -r tools/requirements.txt`.

Консоль, если нужно:

```bash
python tools/pack_chitalka.py ./my-manga --title "Название" --author "Автор" --date 2024-01-01
```

В ридере: щипок / двойной тап — зум страницы, кнопка закладки или клавиша `B`. ZIP копируется в кэш один раз и читается через `ZipFile` по имени файла, без повторного обхода архива.

## Экраны

1. **Библиотека** — список импортированных файлов, FAB «добавить».
2. **Карточка** — обложка, автор, главы, дата, сохранённый прогресс.
3. **Ридер** — вертикальная лента страниц через все главы.

Прогресс: `SharedPreferences` (`mangaId → глава + страница`).

Клавиатура / пульт: вправо/`N`/громкость− — следующая глава, влево/`P`/громкость+ — предыдущая.

Страницы рисуются в `ImageView` (это картинки, не HTML). `WebView` здесь не нужен.

## Android Studio

Откройте папку как проект. Studio подтянет Gradle Wrapper. SDK 35, minSdk 26, Kotlin + View Binding + Material 3.
